# Cat API Project

Cat image viewer built on the [Cat API](https://thecatapi.com).

## Getting Started

Set up the project by following these instructions:

- Install all dependencies with `npm install`
- Create a `.env` file and fill the appropriate variables:
  - VITE_CAT_API_KEY - Your API key from the Cat API's website. Note that this
    project is built as a single-page application and the key would be public.

To run this project:

```bash
# Run the application in development mode
npm run dev

# Build the static bundle
npm run build

# Preview the built output
npm run preview
```
